# Methodology

## Objective

The objective of this project is to organize and present a MOE-based pharmacophore modeling workflow for hERG inhibitor liability assessment.

## Workflow

1. Prepare molecular structures and conformer databases in MOE.
2. Generate and inspect conformational states.
3. Select pharmacophore features based on active-compound patterns.
4. Build a pharmacophore query/model.
5. Screen unknown or candidate compounds against the selected model.
6. Inspect matched hits and evaluate model classification behavior.
7. Summarize performance using true-positive, true-negative, false-positive, and false-negative counts.

## Selected Features

The selected model contains three major features:

- Donor/Acceptor feature
- Hydrophobic feature
- Acceptor feature

These features represent the spatial chemical pattern used for screening compounds in the MOE workflow.
