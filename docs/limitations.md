# Limitations

- The workflow depends on MOE, which is a licensed molecular modeling platform.
- Some MOE database files cannot be meaningfully inspected without MOE.
- The model evaluation summary is based on the recorded dataset and should not be treated as a universal hERG prediction model.
- The available public repository version focuses on workflow organization, model files, selected features, and visual outputs.
- Further validation with larger external datasets would be needed before using this model for production-level screening.
