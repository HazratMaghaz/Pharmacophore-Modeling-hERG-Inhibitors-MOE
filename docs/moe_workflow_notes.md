# MOE Workflow Notes

This project was performed using Molecular Operating Environment (MOE). The repository contains MOE-specific files such as `.mdb`, `.ph4`, and pharmacophore query files.

## Important file types

| File type | Meaning |
|---|---|
| `.mdb` | MOE molecular database / conformer database |
| `.ph4` | MOE pharmacophore model file |
| `.ph4que` / feature query text | Pharmacophore query or feature definition |
| `.jpg` / `.png` | Exported visual outputs from the workflow |

## Reproducibility note

The full interactive reproduction of the workflow requires MOE. However, the repository is structured so that the model files, database files, visual outputs, and evaluation notes are easy to inspect and understand.
